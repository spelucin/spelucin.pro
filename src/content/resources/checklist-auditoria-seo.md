Checklist completa para auditar la salud SEO técnica de una tienda Shopify.

## Indexación

- [ ] Google Search Console: verificar todas las propiedades
- [ ] Revisar覆盖率 de indexación en GSC
- [ ] Verificar que las páginas principales estén indexadas
- [ ] Revisar bloquedores de indexación (noindex, robots.txt, canonical)
- [ ] Verificar sitemap.xml completo y actualizado

## Core Web Vitals

- [ ] LCP < 2.5s en páginas principales
- [ ] CLS < 0.1
- [ ] INP < 200ms
- [ ] Revisar imágenes sin optimizar
- [ ] Verificar carga de fuentes web
- [ ] Revisar scripts de terceros

## Schema Markup

- [ ] Product schema completo (nombre, precio, disponibilidad)
- [ ] Offer schema con precio y moneda
- [ ] Review schema si hay reseñas
- [ ] BreadcrumbList en todas las páginas
- [ ] Organization schema
- [ ] FAQPage en páginas con FAQ

## Arquitectura

- [ ] URLs semánticas y limpias
- [ ] Estructura de navegación lógica
- [ ] Enlaces internos distribuyendo autoridad
- [ ] Filtros/facetas no generan URLs indexables
- [ ] No hay páginas huérfanas
- [ ] Canonicals correctos

## Contenido

- [ ] Títulos únicos y descriptivos
- [ ] Meta descriptions completas
- [ ] H1 únicos por página
- [ ] Contenido en colecciones (no solo grids de productos)
- [ ] Imágenes con alt text descriptivo
